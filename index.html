도입 문의 작동 방식

  • Teamcenter DB 연결 없음

    Teamcenter SOA만으로 모든 데이터를 조회합니다.

  • Teamcenter 설정 변경 없음

    Teamcenter와 license server는 건드리지 않아도 됩니다.

  • Docker로 간편하게 배포

    컨테이너 하나만 올리면 끝

  • Outbound 최대 3곳

    Teamcenter web tier(SOA), SSO login service(SSO 있을경우만), license server 외에는 연결하지 않습니다.

Teamcenter License Dashboard

관리 화면에서 수집 주기와 조회 간격 변경(Teamcenter 수집은 최대 하루 간격)

  1. 1. 화면 열기

    Active Workspace에 로그인한 브라우저에서 바로 열기

  2. 2. 사용 기록 수집

    기본 4시간마다 수집 계정으로 사용자와 월별 사용 기록 조회

  3. 3. 날짜별 접속자 집계

    설치한 날부터 수집할 때마다 마지막 로그인과 월별 로그인 횟수를 비교해 날짜별 접속자를 집계

  4. 4. license server 조회

    기본 1시간마다 license server의 발급 수와 접속 중인 사용자 조회

  5. 5. 집계

    계약 수량 기준으로 실사용률, 잔여 수량, 휴면 후보 계산

기능

등급, 그룹, 모듈, 사용자별 라이선스 사용 현황

01대시보드

등급별 실사용률과 잔여 수량

  • 등급마다 실사용률, 지난달 사용량 스냅샷, 잔여 수량
  • 최대 5년의 월별 추이에서 실사용률과 접속자 가운데 하나를 선택해 표시
  • 잔여 수량 0 이하, 계약 수량 미입력 같은 경고를 맨 위에 표시
  • 휴면 후보, 갱신 수량 산정 근거, 일별 추이까지 한 화면에 표시

02그룹별, 모듈

기본 그룹별, 모듈별 사용 현황

  • 기본 그룹별 할당 사용자, 이번 달 접속자, 할당 대비 접속률
  • 그룹마다 휴면 후보 수
  • 모듈별 보유 수량과 이번 달, 지난달 사용자 수
  • license server 주소를 입력하면 모듈별 발급 수와 만료일 추가

03휴면 후보 명단, 등급 조정 후보

회수와 등급 조정을 검토할 사용자 명단

  • 마지막 접속 후 기본 90일이 지난 사용자
  • 사용하는 날이 적은 Author, 한도를 자주 넘는 Occasional author
  • 지난 90일 활동 기록이 없는 Author(활동 기록 수집 시)
  • 명단마다 CSV 다운로드

04사용자 상세

사용자 한 명의 최근 12개월 사용 기록

  • 최근 12개월의 월별 사용 기록과 일별 접속 달력
  • 달마다 사용한 모듈
  • 사용자 ID 가림을 켜면 가명 번호로 표시

05월간 보고, 내보내기

지난달 월간 보고와 데이터 12종 내보내기

  • 지난달 등급별 월간 집계와 그룹별 표를 인쇄하거나 PDF로 저장
  • 데이터 12종을 기간, 등급, 그룹 조건으로 미리 확인하고 CSV로 다운로드
  • 대시보드의 표마다 CSV 다운로드 버튼 포함

관리

  • 계약 수량과 공휴일 입력
  • 수집 주기와 license server 조회 간격 변경
  • admin, viewer 계정 등록
  • 사용자 ID 가림 설정
  • 감사 로그 확인

활동 기록

  • 객체 생성 건수와 Audit 기록 건수로 실제 작업한 날을 집계
  • admin이 관리 화면에서 수집 시작, 중단, 재개
  • 객체 이름과 내용은 조회하지 않음

수집 계정 로그인비밀번호 혹은 Security Services SSO(COMMSSOCRED)

DB필요 없음

하지 않는 일

  • 사용자 Inactive 전환과 등급 변경 없음
  • 라이선스 계약 수량 산정이나 감사 결과를 대신하지 않음
  • NX 같은 다른 제품, 메일 알림, 다른 프로그램용 API는 지원하지 않음

보안과 권한

Teamcenter 호출

  • SOA operation 10개. 조회 외에 호출하는 operation은 수집 계정 세션의 bypass를 켜는 setUserSessionState 1개
  • 로그아웃하면 Teamcenter가 bypass 해제

license server

  • lmutil의 lmstat만 실행
  • lmdown, lmremove, lmreread 같은 변경 명령은 실행하지 않음
  • 주소를 비우면 조회하지 않음

저장 파일

  • SQLite 파일(권한 600). 수집 계정이 비밀번호로 로그인하면 그 비밀번호도 암호화하지 않고 저장
  • data 폴더의 파일과 수집 계정 비밀번호가 있는 backup 사본은 권한 600으로 관리

화면 권한과 감사 로그

  • admin은 모든 화면을, viewer는 관리 화면을 제외한 화면과 CSV를 사용
  • 계정과 설정 변경, 사용자 상세 열기, 사용자별 데이터 내보내기를 감사 로그에 기록

대시보드가 호출하는 SOA operation 10개

  • Core-2008-06-Session/login
  • Core-2008-06-Session/loginSSO
  • Core-2006-03-Session/logout
  • Core-2007-01-Session/getTCSessionInfo
  • Core-2007-12-Session/setUserSessionState
  • Core-2015-10-Session/getTypeDescriptions2
  • Core-2006-03-DataManagement/getProperties
  • Query-2010-09-SavedQuery/executeBusinessObjectQueries
  • Query-2010-04-SavedQuery/findSavedQueries
  • Query-2007-09-SavedQuery/executeSavedQueries
